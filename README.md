# ROCKY / EV

ROCKY is a local, Windows-first voice and text AI assistant named EV. It combines a locally hosted Llama model with speech recognition, text-to-speech, persistent conversation memory, screenshot capture, and optional retrieval-augmented generation (RAG) over local PDF and text notes.

No cloud API is required by the application code. Chat and embeddings run through a local Ollama installation.

## Features

- Voice conversation through Vosk speech recognition and PyAudio.
- Local Llama chat through Ollama and LangChain.
- Local Piper text-to-speech using the bundled GLaDOS voice model.
- Persistent conversation history in `permanent_memory.json`.
- Automatic history trimming when the message list grows beyond the configured limit.
- RAG search over local `.txt` and `.pdf` files using ChromaDB.
- Desktop screenshot capture with PyAutoGUI.
- Rich terminal output with response panels and retrieval diagnostics.
- Voice version inside main.py
- Text version inside txtinput.py

## Requirements

- Windows.
- Python 3.10 or newer recommended.
- A working microphone for voice mode.
- Ollama installed and running locally.
- Ollama models:
  - `llama3.2:3b`
  - `nomic-embed-text`
- Bundled runtime assets:
  - `vosk_model/` for speech recognition.
  - `piper/piper.exe` and `piper/glados.onnx` for speech synthesis.

The repository includes a pinned `requirements.txt`. Some directly imported packages may need to be installed explicitly if they are not already available, including `pyaudio`, `vosk`, `pyautogui`, `rich`, `langchain-community`, `langchain-text-splitters`, `langchain-ollama`, `langchain-chroma`, `sounddevice`, and `soundfile`.

## Installation

Clone the repository and enter the project directory:

```powershell
git clone <repository-url>
cd ROCKY
```

Create and activate a virtual environment:

```powershell
py -m venv Rockyvenv
.\Rockyvenv\Scripts\Activate.ps1
```

Install dependencies:

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Install any missing direct application dependencies if required:

```powershell
python -m pip install pyaudio vosk pyautogui rich langchain-community langchain-text-splitters langchain-ollama langchain-chroma sounddevice soundfile
```

Start Ollama and pull the required models:

```powershell
ollama pull llama3.2:3b
ollama pull nomic-embed-text
```

## Running EV

### Voice mode

`main.py` listens to the microphone, sends recognized speech to the local Llama model, and reads responses aloud through Piper.

```powershell
python main.py
```

Voice commands include:

- `exit`, `bye`, `goodbye`, or `take five` to stop the assistant.
- `screenshot`, `capture that`, or `clip that` to save a screenshot.

### Text mode

`txtinput.py` provides keyboard input while retaining RAG, memory, screenshot, and Piper output behavior.

```powershell
python txtinput.py
```

Use `exit`, `quit`, `close`, `bye`, or `goodbye` to stop text mode.

## Adding Documents to RAG

Place `.txt` or `.pdf` files under `docs/`, then build the local ChromaDB index:

```powershell
python ingest.py
```

The indexer scans `docs/`, splits documents into 500-character chunks with 50-character overlap, generates embeddings with `nomic-embed-text`, and stores the vectors under `chroma_db/`.

The included `docs/notes/Big_Data_Analytics_5_Mark_Answers.pdf` can be used as an initial indexing source.

## Runtime Notes

- Run commands from the repository root because the application uses relative paths.
- `main.py` requires the `vosk_model/` directory.
- Piper writes generated speech to `ev_output.wav`.
- Screenshots are written to the repository root.
- Conversation history is stored locally in `permanent_memory.json`; treat it as private data.
- `docs/`, `chroma_db/`, model directories, the virtual environment, WAV files, and PNG files are ignored by Git.
- `ingest.py` is the supported command-line indexing entry point.

## Troubleshooting

### Ollama errors

Make sure Ollama is running and both models are available:

```powershell
ollama list
```

### Microphone errors

Check that Windows has granted Python microphone access and that a microphone is available.

### Piper audio errors

Verify that `piper/piper.exe`, `piper/glados.onnx`, and the supporting Piper files remain together.

### Missing Vosk model

Ensure a compatible Vosk model is present at `vosk_model/`.

## Current Limitations

- There is no graphical user interface; interaction occurs through the terminal and audio.
- Voice mode is Windows-oriented and uses the bundled Windows Piper executable.
- RAG must be indexed manually after documents are added or changed.
- The dependency file may need reconciliation with direct imports on a fresh machine.
